# Heisuke's Story — Image Hosting

This repository hosts the image files for *Heisuke's Story*, a
non-commercial fan work (doujinshi) based on *Detective Conan*
(名探偵コナン) by Gosho Aoyama.

The images are served via GitHub Pages and embedded in the work
published on AO3 under the username **ElfSedan**.

## Rights & attribution

All rights to the original characters and settings belong to their
respective rights holders (Gosho Aoyama / Shogakukan / TMS Entertainment
and others). This is an unofficial, non-commercial work made by a fan,
out of love for the series, and claims no ownership over the source
material.

The artwork and story of this doujinshi itself was created by ElfSedan. If you 
share or repost it, please keep the credit and link back to the original AO3 work. 
Thank you.

## Purpose

This repo exists purely to provide stable, long-lived image URLs for
embedding on AO3, which does not host images itself. Keeping the files
in a public repository also means the work can be mirrored and preserved
independently of any single hosting service.

## Structure

```
heisukes-story/
  ep01/
  ep02/
  ...
```

Each episode folder contains the WebP image files for that chapter.
